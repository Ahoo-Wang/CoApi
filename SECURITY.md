# Security Policy

## Supported versions

Security fixes are released for the latest release line of CoApi.
Please upgrade to the [latest release](https://github.com/Ahoo-Wang/CoApi/releases/latest) before reporting.

## Reporting a vulnerability

Please **do not** open a public issue. Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/Ahoo-Wang/CoApi/security/advisories/new).

Include the affected version, a description of the impact and, if possible, a minimal reproduction.
You will receive a response as soon as the report has been reviewed, and the fix will be credited
in the release notes unless you prefer otherwise.
